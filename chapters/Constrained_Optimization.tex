\textbf{Key points (Chapter~\thechapter).}
\begin{enumerate}\setlength{\itemsep}{2pt}
    \item \textbf{Constraints induce a fibre structure.}
    A constraint map $c:\mathbb{R}^P\to\mathbb{R}^k$ partitions parameter space into level sets
    $\mathcal{M}_\theta=\{\theta':c(\theta')=c(\theta)\}$ whose tangent spaces are $\ker(\mathbf{J}_c(\theta))$.
    \item \textbf{Reparameterizing constraints does not change the tangent/normal split.}
    If $\tilde c=\phi\circ c$ with $\phi$ locally invertible, then $\ker(\mathbf{J}_{\tilde c}(\theta))=\ker(\mathbf{J}_c(\theta))$
    and $\mathrm{im}(\mathbf{J}_{\tilde c}(\theta)^\top)=\mathrm{im}(\mathbf{J}_c(\theta)^\top)$.
    \item \textbf{A classical method reappears.}
    Following this geometric splitting yields the \emph{null-space method} for equality constraints:
    a projected step that improves the task loss while (to first order) preserving feasibility, plus a Gauss--Newton-like correction that reduces constraint violation.
    \item \textbf{Matrix-free least squares makes it practical for deep nets.}
    The method only requires Jacobian--vector products with $\mathbf{J}_c$ and $\mathbf{J}_c^\top$ and can therefore be implemented using the same least-squares primitives developed in Chapter~\ref{chap:linalg}.
\end{enumerate}
\end{keypointsbox}

\section{Setting: Equality-Constrained Optimisation in Deep Learning}
\label{sec:constr_setting}

Many desirable inductive biases and structural properties can be expressed as constraints:
physical laws, equivariance/invariance, conservation properties, sparsity budgets, or calibration constraints on intermediate representations.
We consider the equality-constrained learning problem
\begin{align}
\label{eq:constr_opt_nn_ch8}
    \theta^\star \in \arg\min_{\theta\in\mathbb{R}^P}
    \ \mathbb{E}_{x\sim\mathcal{X}}\!\left[\mathcal{L}(\theta;x)\right]
    \quad \text{s.t.}\quad
    c(\theta)=0,
\end{align}
where $\theta\in\mathbb{R}^P$ denotes parameters, $\mathcal{L}$ a task loss, and $c:\mathbb{R}^P\to\mathbb{R}^k$ a continuously differentiable constraint map with $k\ll P$.

Standard optimisers such as SGD or Adam \citep{kingma2014adam} operate in the unconstrained parameter space and do not enforce feasibility.
At a solution, one expects (under regularity conditions) \emph{primal feasibility} $c(\theta^\star)=0$ and \emph{Lagrangian stationarity}:
there exists $\lambda^\star\in\mathbb{R}^k$ such that
\begin{align}
\label{eq:kkt_stationarity}
\nabla_\theta \mathcal{L}(\theta^\star)=\mathbf{J}_c(\theta^\star)^\top \lambda^\star,
\end{align}
where $\mathbf{J}_c(\theta)\in\mathbb{R}^{k\times P}$ is the constraint Jacobian. Simultaneously satisfying both conditions can be difficult in high-dimensional, nonconvex settings.

\section{Constraint Geometry on the Parameter Space}
\label{sec:constr_geometry}
In \cref{chap:setting} we developed a geometry on the parameter space induced by the model map. Specifically, at each parameter $\theta$, the fibres of the model map induce a local decomposition of the tangent space into directions that change the model output and directions where the model output remails constant. Nothing in that construction necessarily requires us to consider the model map. Any function (under some mild conditions) can play the role of model map in that construction. In this section the role of the model map is played by the constraint function $\mathbf{c}: \mathbb{R}^d \to \mathbb{R}^k$ which the defines $k \in \mathbb{N}$ equality constraints.

Following the construction from \cref{chap:setting}, we end up with a parameter space manifold $\Theta$, where at each $\theta$ we can split the tangent space into two different subspaces: $T_\theta\Theta = H_\theta \oplus V_\theta$, where $V_\theta = \texttt{null}(\mathbf{J}_\mathbf{c}(\theta))$ and $H_\theta = \texttt{im}(\mathbf{J}_\mathbf{c}(\theta)^\top)$ is its orthogonal complement. $\mathbf{J}_\mathbf{c}$ is the Jacobian of the constraint function. Finally we can define a metric on this manifold given by $ g_\theta((\delta,\varphi), (\delta', \varphi')) = g^{\mathrm{hor}}_\theta(\delta, \delta') + g^{\mathrm{ver}}_\theta(\varphi, \varphi')$, where $g^{\mathrm{hor}}_\theta$ is a metric on $H_\theta$ and $g^{\mathrm{ver}}_\theta$ is a metric on $V_\theta$. We define $g^{\mathrm{hor}}_\theta = \mathbf{J}_\mathbf{c}(\theta)^\top \mathbf{J}_\mathbf{c}(\theta)$ to be the pullback of the euclidean metric from the output of constraint function, ad $g^{\mathrm{ver}}_\theta = \mathbb{I}$ is the euclidean metric.


The decomposition $T_\theta\Theta = H_\theta \oplus V_\theta$ admits a very direct and useful interpretation in the constrained setting.
A displacement $\varphi\in V_\theta=\texttt{null}(\mathbf{J}_{\mathbf c}(\theta))$ lies in the kernel of the constraint differential, and therefore does \emph{not} change the constraint value to first order:
\begin{align}
\mathbf c(\theta+\varphi)
\;\approx\;
\mathbf c(\theta) + \mathbf{J}_{\mathbf c}(\theta)\,\varphi
\;=\;
\mathbf c(\theta).
\end{align}
Thus, directions in $V_\theta$ are precisely those along which we can reduce the task loss while remaining on the same constraint fibre. This immediately suggests a constrained optimization algorithm. Imagine that we initialize our model to satisfy some constraint. Instead of the usual gradient descent updates, $\theta \leftarrow \theta  \,-  \,\eta  \,\nabla_\theta \mathcal{L}(\theta ; x)$, suppose we project the gradient onto the $V_\theta$ i.e. $\theta \leftarrow \theta - \,\eta \, \textsf{Proj}_V(\theta, \,\nabla_\theta \mathcal{L}(\theta ; x))$. This would give us a gradient descent algorithm that minimizes the task loss while keeping the constraint constant. 

Conversely, a displacement $\delta\in H_\theta=\texttt{im}(\mathbf{J}_{\mathbf c}(\theta)^\top)$ necessarily points in a direction that \emph{does} affect the constraint value (again, to first order).
Indeed, restricting to $H_\theta$ removes the indeterminacy of the constraint Jacobian: on $H_\theta$ the map
\(
\mathbf{J}_{\mathbf c}(\theta):H_\theta\to\mathbb{R}^k
\)
is injective (and under the standard full-row-rank assumption, an isomorphism onto $\mathbb{R}^k$).
This makes $H_\theta$ the natural subspace in which to \emph{ correct} constraint violations. The constraint violation is naturally measured by the squared norm $\tfrac12\|\mathbf c(\theta)\|_2^2$.  For the constraint term, note that $\nabla \tfrac12\|\mathbf c(\theta)\|_2^2 = \mathbf{J}_{\mathbf c}(\theta)^\top \mathbf c(\theta)\in H_\theta$. Thus, the Riemannian gradient of the constraint-violation energy is
\begin{align}
\label{eq:riem_grad_constraint}
(g^{\mathrm{ver}}_\theta)^{-1}\mathbf{J}_{\mathbf c}(\theta)^\top \mathbf c(\theta)
\;=\;
\big(\mathbf{J}_{\mathbf c}(\theta)^\top \mathbf{J}_{\mathbf c}(\theta)\big)^{-1}\mathbf{J}_{\mathbf c}(\theta)^\top \mathbf c(\theta),
\end{align}
This suggests a general constrained optimization algorithm, which does not assume that we satisfy the constraint at initialization. We will make constraint corrections on $H_\theta$ and minimize the task loss on $V_\theta$, which keeps the constraint constant while minimizing the loss. Concretely, this gives us the following update:
\begin{align}
\label{eq:null_space_geom}
    \theta_{t+1} &= \theta_{t} \, - \, \eta \big( \textsf{Proj}_V(\theta, \,\nabla_\theta \mathcal{L}(\theta ; x)) \, +  (g^{\mathrm{ver}}_\theta)^{-1} \nabla \tfrac12\|\mathbf c(\theta)\|_2^2 \big) \\
     \textsf{Proj}_V(\theta, \,\nabla_\theta \mathcal{L}(\theta ; x)) &= \big( \mathbb{I} \, - \, \mathbf{J_{c}}(\theta_t)^{\top}(\mathbf{J_{c}}(\theta_t) \mathbf{J_{c}}(\theta_t)^{\top})^{-1}\mathbf{J_{c}}(\theta_t) \big) \nabla\mathcal{L}(\theta_{t}) \\
     (g^{\mathrm{ver}}_\theta)^{-1} \nabla \tfrac12\|\mathbf c(\theta)\|_2^2 &=  \big(\mathbf{J}_{\mathbf c}(\theta)^\top \mathbf{J}_{\mathbf c}(\theta)\big)^{-1}\mathbf{J}_{\mathbf c}(\theta)^\top \mathbf c(\theta)
\end{align}

\section{Method: The Null-Space Method from a Least-Squares Projection}
\label{sec:constr_method}

We have recovered the \emph{null-space method}~\citep{yamashita1980differential} which proposes an iterative algorithm. Instead of enforcing the constraint directly, \citet{yamashita1980differential} proposes to enforce its first-order approximation, which amounts to solving a sequence of local problems with linearised constraints; for some $\theta_t \in \mathbb{R}^d$, it enforces
\begin{align}
\mathbf{c}(\theta) \approx \mathbf{c}(\theta_t) + \mathbf{J}_\mathbf{c}(\mathbf{\theta}_t)(\mathbf{\theta} - \mathbf{\theta}_t) = \mathbf{0}.
\end{align} 
An algorithm is derived by studying a differential equation whose critical points are the solution to an equality-constrained optimization problem. Discretizing such a flow with learning rates $\eta, \gamma > 0$ yields
% Equation 11: Split to fit column
\begin{subequations}
\begin{align}
\theta_{t+1} &=  \theta_t -\eta \nabla\mathcal{L}(\theta_{t})  + \eta \mathcal{I}_1(\theta_t)+ \gamma\mathcal{I}_2(\theta_t) \\ 
\mathcal{I}_1(\theta_t) &= \mathbf{J_{c}}(\theta_t)^{\top}(\mathbf{J_{c}}(\theta_t) \mathbf{J_{c}}(\theta_t)^{\top})^{-1}\mathbf{J_{c}}(\theta_t) \nabla\mathcal{L}(\theta_{t}) 
\\ 
\mathcal{I}_2(\theta_t) &= \mathbf{J_{c}}(\theta_t)^{\top}(\mathbf{J_{c}}(\theta_t)\mathbf{J_{c}}(\theta_t)^{\top})^{-1}\mathbf{c}(\theta_{t}).
\end{align}
\end{subequations}
One can see that this matches Equation \ref{eq:null_space_geom} exactly, with different learning rates for the gradient in $H_\theta$ and $V_\theta$. 

\paragraph{Numerical Algorithm:}
To turn this into a practical algorithm we need to rewrite the above equation in terms of the primitives from \cref{chap:linalg}. We make the crucial observation that the null-space update term can be written as a single least-squares solve:

\begin{subequations}
\label{eq:local_least_squares}
\begin{align} 
\theta_{t+1} - \theta_t  
&~= -\arg \min_{\{\delta:~ \mathbf{J_{c}}(\theta_t)\delta=-\gamma\mathbf{c}(\theta_{t}) \}} \|\delta - \eta\nabla_{\theta}\mathcal{L}(\theta_t)\|^{2} 
 \label{eq:linearized-constraint}\\
&~= -\eta \nabla_{\theta}\mathcal{L}(\theta_t) 
    + \textsf{LstSq}\big(\mathbf{J}_\mathbf{c}, \eta\mathbf{J_c}\nabla_{\theta}\mathcal{L} - \gamma\mathbf{c}, 0\big).
\label{equation-affine-trafo-gradient}
\end{align}
\end{subequations}

This means that with a single line of code change any state-of-the-art stochastic optimization routines can now be used for solving constrained optimization problems.
We exploit this generality of the null-space method in our code implementation: \Cref{fig:optax_integration} shows that with our library, a few lines of code can turn any of Optax's \citep{deepmind2020jax} gradient transformations into an algorithm for solving constrained optimization problems.

\paragraph{Related Works:}Classical methods for constrained optimisation include penalty methods, Lagrangian methods, and projected gradient descent \citep{nocedal1999numerical}. 
% \begin{itemize} 
% \item 
Penalty methods 
turn a constrained problem into an unconstrained one by adding a penalty term to the loss. However, for finite penalty weights, penalty methods do not satisfy primal feasibility upon convergence \citep{nocedal1999numerical}, and a large penalty weight can distort the optimisation landscape, leading to poor solutions for the task loss.
\Cref{figure:combined_optimizers_plot} shows this issue.
% \item 
Another approach to constrained optimisation is to optimise an (augmented) Lagrangian.
However, this requires finding saddle points rather than minima, which complicates the use of typical gradient-based (stochastic) optimisation routines, leading to intricate update schemes that can be difficult to tune \citep{alma991013887829703276}. 
% \item 
Finally, projected gradient descent (PGD) is an iterative method that alternates between a standard gradient update on the task loss and a projection step onto the feasible set defined by $\mathbf{c}(\mathbf{\theta})=\mathbf{0}$. While conceptually straightforward, the projection step is computationally expensive or analytically intractable for most constraints. Thus, PGD is often limited to simple problems, and does not generalise to the applications we demonstrate in \Cref{sec:constr_experiments}. 
% \end{itemize}

\section{Demonstrations}
\label{sec:constr_experiments}
Next, we demonstrate the capabilities of the null-space method using various practical constraints. 
The focal points are, next to good performance, versatility, and ease of application; thus, the benchmarks below prefer baselines that are typical to each constraint over those that are carefully-tuned state-of-the-art implementations.
To make things fair, we use equally little fine-tuning for our approach -- the results are surprisingly strong. 
We anticipate that domain-specific optimisations could further enhance performance and scalability in each application. 

\textbf{Enforcing equivariance:~~}
% \label{sec: equivariance_expts}
The null-space method enables the enforcement of complex functional properties like equivariance and invariance directly during training, without the need for bespoke architectures. These properties act as powerful structural priors, guiding the model to learn representations that respect known symmetries or are robust to specific nuisance transformations in the input data.

\textit{Rotation Equivariance:} We enforce $C_4$ rotational equivariance \citep{cohen2016group} on the convolutional layers of a LeNet \citep{726791} model trained on FMNIST \citep{xiao2017fashion}. The constraint $\mathbf{c}(\mathbf{\theta})$ minimises the difference between final feature maps resulting from rotating the input image and rotating the final output feature maps, ensuring the learned filters respect $C_4$ rotational symmetry (i.e., $f(R\mathbf{x}; \mathbf{\theta}) - R f(\mathbf{x}; \mathbf{\theta}) = \mathbf{0}$ for $C_4$ rotation $R$). The results in \Cref{tab:equiv_invariance_results} show that the null-space method balances the task loss and constraint satisfaction: it achieves slightly lower test accuracy compared to ``ordinarily trained'' models but exhibits vastly superior satisfaction of $C_4$ equivariance.

\textit{$O(3)$ Equivariance:}
A key strength of our null-space method is its ability to impose complex group equivariances by changing just a few lines of code to define the constraint. We demonstrate this by enforcing $O(3)$ equivariance on the task of predicting the moment of inertia for particle systems \citep{finzi2021practical}. We randomly sample transformations $R\in O(3)$ and the constraint $f(R\mathbf{x}; \mathbf{\theta}) - R^\top f(\mathbf{x} ; \mathbf{\theta}) R = \mathbf{0}$.
Then, we benchmark our null-space method against a baseline that uses $O(3)$ data augmentation. Performance is evaluated on a test dataset by measuring the mean squared error (MSE) on a test set and the $O(3)$ equivariance constraint violation (\Cref{tab:equiv_invariance_results}). The null-space method outperforms data augmentation in both metrics.

\textbf{Enforcing $\ell_0$ sparsity:~~}
% \label{sec:l0_sparsity}
Enforcing a specific $\ell_0$ sparsity level during training can be achieved using learnable stochastic masks \citep{louizos2017learning, gallego2022controlled}. 
We optimise mask-probabilities $\mathbf{p}$ alongside model weights $\mathbf{\theta}$, and sample masks from a Bernoulli distribution, using \citet{yin2019understanding}'s straight-through estimator for $\mathbf{p}$'s gradients derived from the task loss. Our constrained optimization method is applied to $\mathbf{p}$ via a constraint $c(\mathbf{p}) = \frac{1}{N_p} \sum_{i=1}^{N_p} p_i - s_{\text{target}} = 0$, where $N_p$ is the total number of parameters, which drives the expected proportion of active weights towards a target sparsity level $s_{\text{target}}$.
We apply this method to train ResNet-18 \citep{he2016deep} on CIFAR-10 \citep{krizhevsky2009learning} (target $s_{\text{target}}=0.1$, i.e., 90\% sparsity) and SWIN-S \citep{liu2021swin} on ImageNet \citep{deng2009imagenet, russakovsky2015imagenet} (target $s_{\text{target}}=0.5$, i.e., 50\% sparsity). We compare against one-shot magnitude pruning~\citep{lee2024jaxpruner} as a baseline. \Cref{tab:l0_sparsity_results} shows that the null-space method achieves better test accuracies than magnitude pruning.

\textbf{Conservative property of score-based generative models:~~}
% \label{sec:conservative}
Score-based generative models learn the score function $\mathbf{s}(\mathbf{x}; \mathbf{\theta}) = \nabla_{\mathbf{x}} \log p_d(\mathbf{x})$, where $p_d(\mathbf{x})$ is the data distribution. For $\mathbf{s}$ to be a valid score function, it must be a conservative vector field, implying its Jacobian must be symmetric, $\mathbf{J}(\mathbf{s}) - \mathbf{J}(\mathbf{s})^\top = \mathbf{0}$; see \citep{chao2022investigating} for details. We apply the null-space method to enforce this conservativeness constraint $\mathbf{c}(\mathbf{\theta}) = ||\mathbf{J}(\mathbf{s}) - \mathbf{J}(\mathbf{s})^\top||_F^2 = 0$ during training. This encourages score-based models that are both architecturally flexible and theoretically sound.
We compare our null-space method to typical unconstrained score-based models (USBMs) and \citet{chao2022investigating}'s quasi-conservative score-based models (QCSBM) on various synthetic 2D datasets. The performance is evaluated via asymmetry (Asym), normalised asymmetry (NAsym), score error, and negative log-likelihood (NLL). The results in \Cref{tab:conservative_sbm_results} show that the null-space method outperforms the baselines by achieving the best NLL and a stricter enforcement of conservativeness.
