\chapter{What is the Parameter Space Like}
\label{chap:setting}

\begin{keypointsbox}
\noindent
\textbf{Key points (Chapter~\ref{chap:setting}).}
\begin{enumerate}\setlength{\itemsep}{2pt}
  \item \textbf{The dataset-restricted model map.}
  A Bayesian model induces a smooth map \(F_{\mathcal D}:\Theta \to \mathcal Z\) from parameters
  to dataset-restricted predictive quantities (e.g. logits or natural parameters). The fibres
  \(F_{\mathcal D}^{-1}(z)\) are precisely the sets of parameters that are indistinguishable on the dataset.

  \item \textbf{Local product structure on regular regions.}
  On regions where \(F_{\mathcal D}\) has constant rank, fibres are smooth submanifolds and the parameter
  space admits local coordinates in which it looks like a product
  \(\text{(prediction-changing)} \times \text{(prediction-preserving)}\).

  \item \textbf{Intrinsic splitting via an Ehresmann connection.}
  Choosing a horizontal complement to the vertical space \(\ker(dF_{\mathcal D})\) defines an Ehresmann
  connection, giving an intrinsic decomposition \(T_\theta\Theta = H_\theta \oplus V_\theta\) without relying
  on an embedded “image manifold”.

  \item \textbf{Why Bayes cares.}
  Posterior mass and uncertainty should respect this structure: vertical directions capture symmetries /
  non-identifiabilities, while horizontal directions control changes in predictions. This viewpoint clarifies
  how approximations (Laplace, VI) and samplers (MCMC) can be designed to move efficiently across fibres.
\end{enumerate}
\end{keypointsbox}

\noindent
This chapter builds the geometric foundation used throughout the thesis. The guiding idea is that,
for a fixed dataset \(\mathcal D\), a model is best understood through the dataset-restricted \emph{forward map}
\(F_{\mathcal D}:\Theta \to \mathcal Z\) that sends parameters to predictive quantities (e.g. logits).
Parameters that produce identical predictions on \(\mathcal D\) lie on the same \emph{fibre}
\(F_{\mathcal D}^{-1}(z)\), and these fibres capture the model's non-identifiabilities and symmetries.

Under mild regularity conditions, the parameter space admits a \emph{local product} structure: a decomposition of the parameter space into directions that change predictions and directions that move within fibres. The upshot of this construction is that Bayesian computation takes place on a parameter space that is not Euclidean, but instead carries a geometry explicitly accounting for \emph{reparameterizations} of the forward map—here, a neural network

We begin with an informal treatment anchored in the linear-Gaussian case, where the decomposition is global and explicit, and provide an intuitive description of what the parameter space looks like. This is followed by a more rigorous formal treatment where we formalize the intuitive descriptions to describe the parameter space as a Riemannian manifold. Finally, we briefly discuss the consequences of this construction and foreshadow the rest of the thesis.


\section{Informal picture: Parameter Space as a local product space} 
\label{sec:informal_local_product}

\subsection{Global product space in the linear--Gaussian case}
\label{subsec:linear_gaussian_global_product}

To build intuition on the geometry of the parameter space without any differential geometry we begin with Bayesian Linear Regression with a Gaussian prior and Gaussian likelihood. In this model, the parameter space
really \emph{is} a global product: there is a whole subspace of directions that do not change the dataset-restricted predictions at all.

\paragraph{Model and the dataset-restricted map.}
Let $\theta\in\Theta=\mathbb{R}^P$. Consider a linear forward map
\[
  f_\theta(x) \;=\; x^\top \theta \in \mathbb{R}.
\]
Given a supervised dataset $\mathcal{D}=\{(x^{(n)},y^{(n)})\}_{n=1}^N$, stack the inputs into the design matrix
$X\in\mathbb{R}^{N\times P}$ with rows $(x^{(n)})^\top$, and stack labels into $Y\in\mathbb{R}^N$.
The dataset-restricted prediction map is
\[
  F_{\mathcal{D}}(\theta)
  \;:=\;
  \begin{bmatrix}
    f_\theta(x^{(1)})\\ \vdots\\ f_\theta(x^{(N)})
  \end{bmatrix}
  \;=\; X\theta \in \mathbb{R}^N.
\]
We have the following likelihood and prior models:
\[
\underbrace{
Y \mid \theta \sim \mathcal{N}(X\theta,\sigma^2 I)
}_{\scriptstyle \text{likelihood}}
\qquad
\underbrace{
\theta \sim \mathcal{N}(0,\tau^2 I)
}_{\scriptstyle \text{prior}}
\]

\paragraph{Fibres are affine subspaces (parallel ``sheets'').}
Two parameters $\theta,\theta'$ are indistinguishable on the dataset iff $X\theta=X\theta'$,
i.e.\ iff $X(\theta-\theta')=0$. So the fibre through $\theta$ is
\[
  F_{\mathcal{D}}^{-1}(X\theta)
  \;=\;
  \theta + \ker(X).
\]
This is already the core intuition: \emph{moving inside $\ker(X)$ does not change the logits/predictions on the dataset}.
Geometrically, parameter space is foliated by parallel affine subspaces (``sheets'').

\paragraph{A global splitting: prediction-changing vs prediction-preserving.}
Because $F_{\mathcal{D}}$ is a linear map, there is a global, dataset-dependent decomposition of parameter space into the kernel subspace and a co-image subspace:
\[
  \mathbb{R}^P
  \;=\;
  \underbrace{\ker(X)}_{\text{prediction-preserving}}
  \;\oplus\;
  \underbrace{\mathrm{im}(X^\top)}_{\text{prediction-changing (row space)}}.
\]
Every $\theta$ can be uniquely written as
\[
  \theta = \theta_{\parallel} + \theta_{\perp},
  \qquad
  \theta_{\parallel}\in \mathrm{im}(X^\top),\;\; \theta_{\perp}\in \ker(X),
\]
and crucially
\[
  X\theta = X\theta_{\parallel}
  \quad\text{(the dataset predictions ignore }\theta_{\perp}\text{ entirely).}
\]

\paragraph{Posterior factorization: Bayes learns only on the row space.}
In this model the posterior is exactly Gaussian:
\[
  p(\theta\mid \mathcal{D})
  \;=\;
  \mathcal{N}\!\bigl(\theta \,;\, m,\Sigma\bigr),
  \qquad
  \Sigma^{-1} = \tau^{-2}I + \sigma^{-2}X^\top X,
  \qquad
  m = \sigma^{-2}\Sigma X^\top y.
\]
The key structural fact is that the likelihood depends only on $X\theta$, hence only on the component
$\theta_{\parallel}\in\mathrm{im}(X^\top)$.
If the prior is isotropic Gaussian, it also respects the orthogonal splitting
$\mathbb{R}^P = \mathrm{im}(X^\top)\oplus \ker(X)$, which means the posterior separates into:
\[
  p(\theta\mid\mathcal{D})
  \;=\;
  p(\theta_{\parallel}\mid\mathcal{D})\; p(\theta_{\perp}),
\]
where $\theta_{\perp}\sim\mathcal{N}(0,\tau^2 I)$ remains \emph{unchanged by the data}.
Intuitively: the data can only update what it can see, and on the dataset it can only see the row-space
component.



\paragraph{Posterior factorization: Bayes learns only on the row space.}
In this model the posterior is exactly Gaussian,
\[
  p(\theta\mid \mathcal{D})
  \;=\;
  \mathcal{N}\!\bigl(\theta \,;\, m,\Sigma\bigr),
  \qquad
  \Sigma^{-1} = \tau^{-2}I + \sigma^{-2}X^\top X,
  \qquad
  m = \sigma^{-2}\Sigma X^\top y.
\]
But the key point is not merely tractability: it is that Bayesian updating \emph{acts only through}
the dataset-restricted map \(F_{\mathcal D}(\theta)=X\theta\).
Equivalently, the likelihood depends on \(\theta\) only via \(z:=X\theta\), so inference can be viewed
as first updating \(z\) (a Gaussian variable in \(\mathbb R^N\)) and then lifting back to parameter space along the fibres
\(\theta+\ker(X)\). In this linear setting, conditioning ``along the map'' coincides with conditioning on the affine fibre,
because the map has constant Jacobian: the conditional measure on a fibre is simply the prior restricted to that fibre.

To make the geometry explicit, choose an orthogonal splitting
\(\mathbb{R}^P = \mathrm{im}(X^\top)\oplus \ker(X)\) and write \(\theta=\theta_{\parallel}+\theta_{\perp}\).
Then \(m\in \mathrm{im}(X^\top)\), and the posterior covariance contracts only in the data-visible directions:
if \(s_1,\dots,s_r\) are the nonzero singular values of \(X\), the posterior variances along the corresponding right-singular
directions are \((\tau^{-2}+\sigma^{-2}s_i^2)^{-1}\), whereas along every fibre direction in \(\ker(X)\) they remain exactly \(\tau^2\).
In particular, for an isotropic prior the posterior \emph{disintegrates} as
\[
  p(\theta\mid\mathcal{D})
  \;=\;
  p(\theta_{\parallel}\mid\mathcal{D})\; p(\theta_{\perp}),
  \qquad
  \theta_{\perp}\sim\mathcal{N}(0,\tau^2 I)\ \ \text{independent of } \mathcal D,
\]
so the data can only update what it can ``see'' through \(X\).

This has a sharp predictive consequence. For a new input \(x_\*\), decompose \(x_\*=x_{\*,\parallel}+x_{\*,\perp}\) with
\(x_{\*,\parallel}\in\mathrm{im}(X^\top)\) and \(x_{\*,\perp}\in\ker(X)\). Then the epistemic part of the predictive variance splits as
\[
  \mathrm{Var}_{\theta\mid \mathcal D}\!\bigl[x_\*^\top \theta\bigr]
  \;=\;
  x_{\*,\parallel}^\top \Sigma\,x_{\*,\parallel}
  \;+\;
  \tau^2 \,\|x_{\*,\perp}\|^2.
\]
Thus any component of \(x_\*\) orthogonal to the training row space induces an \emph{irreducible prior-dominated} uncertainty term:
even in this fully tractable model, the fibre directions are invisible on \(\mathcal D\) yet can matter off \(\mathcal D\).

\paragraph{A one-sentence intuition pump.}
\emph{Linear regression with $P>N$ is the simplest example of ``sloppy directions'': there is a whole
subspace of parameters that produces identical dataset predictions, and the posterior cannot learn there
unless the prior breaks the symmetry.}

\paragraph{Why this matters for deep nets (preview of the next subsection).}
For neural networks, $F_{\mathcal D}(\theta)$ is no longer linear in $\theta$.
But near any reference point $\theta_0$, we can locally linearize:
\[
  F_{\mathcal D}(\theta_0 + \delta)
  \;\approx\;
  F_{\mathcal D}(\theta_0) + J_{\mathcal D}(\theta_0)\,\delta,
\]
where $J_{\mathcal D}(\theta_0)$ is the stacked Jacobian of dataset-restricted predictions.
This is the nonlinear analogue of $X$.
In the next subsection, we use this local linear picture to motivate a \emph{local} product structure:
directions in $\ker(J_{\mathcal D}(\theta_0))$ are (to first order) prediction-preserving, while a complementary
subspace controls changes in predictions. This is the geometric seed of the fibre bundle viewpoint.



\subsection{From global to local: linearization gives a local product space}
\label{subsec:local_linearization_product}

The linear--Gaussian case is unusually clean because the dataset-restricted model map
\(F_{\mathcal D}(\theta)=X\theta\) is linear, so the ``fibre directions'' \(\ker(X)\) and the
``prediction-changing directions'' \(\mathrm{im}(X^\top)\) form a \emph{global} decomposition of
\(\mathbb{R}^P\). For neural networks, we should not expect any global linear structure.
However, the key lesson survives: \emph{locally, the model map looks linear}, and therefore
the parameter space looks like a \emph{local} product of fibre directions and prediction-changing directions.

\paragraph{The dataset-restricted model map.}
Recall that the network produces distributional parameters
\(u_\theta(x)=f_\theta(x)\in\mathcal U\), and the per-datum likelihood is
\(p(y\mid f_\theta(x))\).
Fix a dataset \(\mathcal D=\{(x^{(n)},y^{(n)})\}_{n=1}^N\). The central object of this chapter is the
\emph{dataset-restricted prediction map}
\begin{equation}
  F_{\mathcal D}:\Theta\to\mathcal U^N,
  \qquad
  F_{\mathcal D}(\theta)
  \;:=\;
  \bigl(f_\theta(x^{(1)}),\dots,f_\theta(x^{(N)})\bigr).
  \label{eq:dataset_restricted_map}
\end{equation}
(You can think of \(\mathcal U^N\) as a ``stacked logit space'' or ``stacked natural-parameter space''.)
By construction, the likelihood depends on \(\theta\) only through \(F_{\mathcal D}(\theta)\):
\[
  p(\mathcal D\mid \theta)
  \;=\;
  \prod_{n=1}^N p\bigl(y^{(n)}\mid f_\theta(x^{(n)})\bigr)
  \;=\;
  \mathcal{L}\!\bigl(F_{\mathcal D}(\theta)\bigr)
\]
for a suitable function \(\mathcal{L}:\mathcal U^N\to\mathbb{R}_+\).

\paragraph{Fibres: ``indistinguishable on the dataset''.}
For any \(z\in\mathcal U^N\), the fibre (preimage) is
\begin{equation}
  \mathcal F_z
  \;:=\;
  F_{\mathcal D}^{-1}(z)
  \;=\;
  \{\theta\in\Theta : F_{\mathcal D}(\theta)=z\}.
  \label{eq:fibre_def}
\end{equation}
These are precisely the sets of parameters that produce identical predictions on all training inputs.
When \(f_\theta\) is overparameterized, such fibres can be high-dimensional and can contain
reparameterizations/symmetries (e.g.\ hidden-unit permutations or scaling symmetries).

\paragraph{Local linearization: replacing a network by its first-order approximation.}
Fix a reference point \(\theta_0\in\Theta\) and consider a small perturbation \(\delta\).
A first-order Taylor approximation gives
\begin{equation}
  F_{\mathcal D}(\theta_0+\delta)
  \;\approx\;
  F_{\mathcal D}(\theta_0) \;+\; J_{\mathcal D}(\theta_0)\,\delta,
  \label{eq:local_linearization}
\end{equation}
where
\[
  J_{\mathcal D}(\theta_0)
  \;:=\;
  dF_{\mathcal D}(\theta_0)
\]
is the Jacobian (differential) of the dataset-restricted map. Concretely, it is the stacked Jacobian of
the network outputs at the training inputs. This plays the same role as the design matrix \(X\) in the
linear example.

\paragraph{The first-order ``fibre directions'' are the Jacobian nullspace.}
Equation \eqref{eq:local_linearization} makes one fact immediate:
if \(\delta\in\ker(J_{\mathcal D}(\theta_0))\), then to first order
\[
  F_{\mathcal D}(\theta_0+\delta)\;\approx\;F_{\mathcal D}(\theta_0),
\]
so \(\delta\) is (infinitesimally) prediction-preserving on the dataset. This motivates the definition
of the \emph{vertical space} at \(\theta_0\):
\begin{equation}
  V_{\theta_0}
  \;:=\;
  \ker\!\bigl(dF_{\mathcal D}(\theta_0)\bigr)
  \;=\;
  \ker\!\bigl(J_{\mathcal D}(\theta_0)\bigr),
  \label{eq:vertical_space}
\end{equation}
the tangent directions that do not change dataset predictions (to first order).
In the linear model \(F_{\mathcal D}(\theta)=X\theta\), this reduces to \(V_\theta=\ker(X)\) for all \(\theta\),
which is why the decomposition was global.

\paragraph{Prediction-changing directions: choosing a complement (a ``horizontal'' space).}
The Jacobian also identifies the directions that \emph{do} change predictions.
Any vector \(\delta\) with \(J_{\mathcal D}(\theta_0)\delta\neq 0\) moves the logits in the stacked output space.
To turn this into a clean local product picture, we want to split the full tangent space as
\begin{equation}
  T_{\theta_0}\Theta
  \;\cong\;
  H_{\theta_0}\;\oplus\;V_{\theta_0},
  \qquad
  V_{\theta_0}=\ker(J_{\mathcal D}(\theta_0)),
  \label{eq:local_split_goal}
\end{equation}
where \(H_{\theta_0}\) is any complementary subspace (a choice of ``prediction-changing directions'').

At the informal level, you can think of \(H_{\theta_0}\) as the directions that move you \emph{across} fibres,
while \(V_{\theta_0}\) moves you \emph{along} a fibre. The key subtlety is that in nonlinear models this choice
need not be canonical: different complements correspond to different ways of ``lifting'' a desired change in
predictions back to a parameter update. This is exactly the motivation for introducing an Ehresmann connection
in the formal section.

\paragraph{Local product structure in words (what to remember).}
The linear case taught us that ``dataset predictions'' live in a lower-dimensional space, and parameters
contain extra degrees of freedom that the dataset cannot see. The nonlinear case keeps exactly the same story,
but only \emph{locally}:
\begin{itemize}[leftmargin=1.4em,itemsep=0.25em]
  \item the map \(F_{\mathcal D}\) replaces the design matrix \(X\);
  \item the nullspace \(\ker(J_{\mathcal D}(\theta_0))\) gives the \emph{local} fibre directions at \(\theta_0\);
  \item a complementary subspace gives the \emph{local} directions that change predictions;
  \item these two pieces vary with \(\theta\), so the ``product'' picture is local rather than global.
\end{itemize}

\paragraph{Bridge to the next (formal) subsection.}
Up to now, we have treated the splitting \eqref{eq:local_split_goal} as a local linear-algebraic convenience.
The next step is to formalize when fibres are genuine smooth submanifolds and when such local product charts exist.
On regions where \(F_{\mathcal D}\) has constant rank, differential topology guarantees exactly this:
the parameter space admits local coordinates in which \(F_{\mathcal D}\) is a projection, and the fibres are smooth
leaves. Introducing an Ehresmann connection then promotes the pointwise choice of complements \(H_{\theta}\) into a
smooth field of horizontal spaces, yielding the intrinsic fibre bundle picture used throughout the thesis.

\subsection{From linear to nonlinear: global subspaces become local distributions}
\label{subsec:nonlinear_localization}

\noindent \textit{(Nonlinear case.)} For neural networks the forward map $F$ is nonlinear, so the Jacobian
\[
J_\theta := dF_\theta
\]
depends on $\theta$. As a result, the vertical directions
\[
\mathrm{Ver}_\theta := \ker(J_\theta)
\]
and the corresponding ``horizontal complements'' vary from point to point. In other words, the global decomposition
\eqref{eq:linear_global_split} is replaced by a \emph{local} decomposition of tangent spaces:
\begin{equation}
\label{eq:local_split}
T_\theta\Theta \;=\; \underbrace{\ker(dF_\theta)}_{\mathrm{Ver}_\theta}
\ \oplus\ 
\underbrace{\mathrm{Hor}_\theta}_{\text{chosen complement}},
\qquad \theta\ \text{in a regular region}.
\end{equation}

\noindent The key message is that \emph{even though the fibres may twist globally}, near a \emph{regular point}
(the regime where the rank of $dF_\theta$ is locally constant) there exist local coordinates in which the map $F$
looks like a projection. This is exactly the ``local product'' behavior captured by the notion of a fibre bundle.

\medskip
\noindent \textit{(Ehresmann connection, informally.)} A smooth choice of complements $\mathrm{Hor}_\theta$ in
\eqref{eq:local_split} is called an \emph{Ehresmann connection}. It formalizes the idea of ``moving across fibres''
versus ``moving along fibres'' and will later allow us to identify $\mathrm{Hor}_\theta$ with tangent directions in the
base (prediction) manifold.

% ============================================================
\subsection{Background}
\label{subsec:formal_background}
% ============================================================

\noindent We recall the minimal differential-geometric vocabulary needed to formalize the local product picture from
Section~\ref{sec:informal_local_product}. All objects will later be instantiated by the dataset-restricted prediction
map arising from a Bayesian model.

\begin{gdefn}[Smooth manifold and differential]
A \emph{smooth manifold} $M$ of dimension $d$ is a Hausdorff, second countable topological space equipped with an atlas
of charts $(U,\psi)$ where $\psi:U\to \mathbb{R}^d$ are homeomorphisms with smooth transition maps.
For $p\in M$, the \emph{tangent space} at $p$ is denoted $T_pM$ and the \emph{tangent bundle} is
$TM := \bigsqcup_{p\in M} T_pM$.

Given a smooth map $G:M\to N$, its \emph{differential} at $p$ is the linear map
\[
dG_p : T_pM \to T_{G(p)}N.
\]
We write $\ker(dG_p)\subset T_pM$ for its kernel and $\mathrm{rank}(dG_p)$ for its rank.
\end{gdefn}

\begin{gdefn}[Constant rank and submersion]
A smooth map $G:M\to N$ has \emph{constant rank $r$} on a set $U\subseteq M$ if $\mathrm{rank}(dG_p)=r$ for all $p\in U$.
It is a \emph{submersion} at $p\in M$ if $dG_p$ is surjective.
\end{gdefn}

\begin{gthm}[Constant Rank Theorem (local normal form)]
Let $G:M\to N$ be smooth and suppose $\mathrm{rank}(dG_p)=r$ is constant on a neighborhood of $p\in M$.
Then there exist charts $(U,\psi)$ around $p$ and $(V,\phi)$ around $G(p)$ such that in coordinates
\[
(\phi\circ G\circ \psi^{-1})(a,b) = (a,0),
\qquad (a,b)\in \mathbb{R}^r\times \mathbb{R}^{\dim M-r}.
\]
\end{gthm}

\begin{gdefn}[Smooth fibre bundle]
A \emph{smooth fibre bundle} is a quadruple $(E,B,F,\pi)$ where $E$ and $B$ are smooth manifolds,
$F$ is a smooth manifold (the \emph{typical fibre}), and $\pi:E\to B$ is a smooth surjection such that:

\smallskip
\noindent\textbf{(Local triviality)} For every $b\in B$, there exists an open neighborhood $U\subset B$ and a diffeomorphism
(a \emph{local trivialization})
\[
\varphi_U : U\times F \to \pi^{-1}(U)
\]
satisfying $\pi\circ \varphi_U = \mathrm{pr}_1$, the projection onto the first factor.

\smallskip
\noindent The \emph{fibre over $b$} is $E_b := \pi^{-1}(b)$.
\end{gdefn}

\begin{gdefn}[Vertical bundle and Ehresmann connection]
Let $\pi:E\to B$ be a smooth surjection. The \emph{vertical subspace} at $e\in E$ is
\[
\mathrm{Ver}_e := \ker(d\pi_e)\subset T_eE.
\]
An \emph{Ehresmann connection} is a smooth choice of complementary subspaces $\mathrm{Hor}_e\subset T_eE$ such that
\[
T_eE = \mathrm{Ver}_e \oplus \mathrm{Hor}_e \qquad \text{for all } e\in E.
\]
The subspaces $\mathrm{Hor}_e$ are called the \emph{horizontal spaces}.
\end{gdefn}


\section{Informal picture: Parameter Space as a local product space}
\label{sec:informal_local_product}

\subsection{Global product space in the linear--Gaussian case}
\label{subsec:linear_gaussian_global_product}

The cleanest place to see the ``bundle picture'' without any differential geometry is ordinary
linear regression with a Gaussian prior and Gaussian noise. In this model, the parameter space
really \emph{is} a global product: there is a whole subspace of directions that do not change the
dataset-restricted predictions at all, and the posterior simply cannot learn along those directions.

\paragraph{Model and the dataset-restricted map.}
Let $\theta\in\Theta=\mathbb{R}^P$. Consider the linear predictor
\[
  f_\theta(x) \;=\; \theta^\top x \in \mathbb{R}.
\]
Given a supervised dataset $\mathcal{D}=\{(x^{(n)},y^{(n)})\}_{n=1}^N$, stack the inputs into the design matrix
$X\in\mathbb{R}^{N\times P}$ with rows $(x^{(n)})^\top$, and stack labels into $y\in\mathbb{R}^N$.
The dataset-restricted prediction map is
\[
  F_{\mathcal{D}}(\theta)
  \;:=\;
  \begin{bmatrix}
    f_\theta(x^{(1)})\\ \vdots\\ f_\theta(x^{(N)})
  \end{bmatrix}
  \;=\; X\theta \in \mathbb{R}^N.
\]
We take a Gaussian observation model and prior:
\[
  y \mid \theta \sim \mathcal{N}(X\theta,\sigma^2 I),
  \qquad
  \theta \sim \mathcal{N}(0,\tau^2 I).
\]

\paragraph{Fibres are affine subspaces (parallel ``sheets'').}
Two parameters $\theta,\theta'$ are indistinguishable on the dataset iff $X\theta=X\theta'$,
i.e.\ iff $X(\theta-\theta')=0$. So the fibre through $\theta$ is
\[
  F_{\mathcal{D}}^{-1}(X\theta)
  \;=\;
  \theta + \ker(X).
\]
This is already the core intuition: \emph{moving inside $\ker(X)$ does not change the logits/predictions on the dataset}.
Geometrically, parameter space is foliated by parallel affine subspaces (``sheets'').
Figure~\ref{fig:fibre_cartoon} is the schematic version of this idea: fibres are level sets of the prediction map $F$.

Because $X$ is linear, there is a global, dataset-dependent decomposition of parameter space:
\[
  \mathbb{R}^P
  \;=\;
  \underbrace{\ker(X)}_{\text{prediction-preserving}}
  \;\oplus\;
  \underbrace{\mathrm{im}(X^\top)}_{\text{prediction-changing (row space)}}.
\]
Every $\theta$ can be uniquely written as
\[
  \theta = \theta_{\parallel} + \theta_{\perp},
  \qquad
  \theta_{\parallel}\in \mathrm{im}(X^\top),\;\; \theta_{\perp}\in \ker(X),
\]
and crucially
\[
  X\theta = X\theta_{\parallel}
  \quad\text{(the dataset predictions ignore }\theta_{\perp}\text{ entirely).}
\]

\paragraph{Posterior factorization: Bayes learns only on the row space.}
In this model the posterior is exactly Gaussian:
\[
  p(\theta\mid \mathcal{D})
  \;=\;
  \mathcal{N}\!\bigl(\theta \,;\, m,\Sigma\bigr),
  \qquad
  \Sigma^{-1} = \tau^{-2}I + \sigma^{-2}X^\top X,
  \qquad
  m = \sigma^{-2}\Sigma X^\top y.
\]
The key structural fact is that the likelihood depends only on $X\theta$, hence only on the component
$\theta_{\parallel}\in\mathrm{im}(X^\top)$.
If the prior is isotropic Gaussian, it also respects the orthogonal splitting
$\mathbb{R}^P = \mathrm{im}(X^\top)\oplus \ker(X)$, which means the posterior separates into:
\[
  p(\theta\mid\mathcal{D})
  \;=\;
  p(\theta_{\parallel}\mid\mathcal{D})\; p(\theta_{\perp}),
\]
where $\theta_{\perp}\sim\mathcal{N}(0,\tau^2 I)$ remains \emph{unchanged by the data}.
Intuitively: the data can only update what it can see, and on the dataset it can only see the row-space
component.

\paragraph{A one-sentence intuition pump.}
\emph{Linear regression with $P>N$ is the simplest example of ``sloppy directions'': there is a whole
subspace of parameters that produces identical dataset predictions, and the posterior cannot learn there
unless the prior breaks the symmetry.}

\paragraph{Why this matters for deep nets (preview of the next subsection).}
For neural networks, $F_{\mathcal D}(\theta)$ is no longer linear in $\theta$.
But near any reference point $\theta_0$, we can locally linearize:
\[
  F_{\mathcal D}(\theta_0 + \delta)
  \;\approx\;
  F_{\mathcal D}(\theta_0) + J_{\mathcal D}(\theta_0)\,\delta,
\]
where $J_{\mathcal D}(\theta_0)$ is the stacked Jacobian of dataset-restricted predictions.
This is the nonlinear analogue of $X$.
In the next subsection, we use this local linear picture to motivate a \emph{local} product structure:
directions in $\ker(J_{\mathcal D}(\theta_0))$ are (to first order) prediction-preserving, while a complementary
subspace controls changes in predictions. This is the geometric seed of the fibre bundle viewpoint.


\subsection{From global to local: linearization gives a local product space}
\label{subsec:local_linearization_product}

The linear--Gaussian case is unusually clean because the dataset-restricted model map
\(F_{\mathcal D}(\theta)=X\theta\) is linear, so the ``fibre directions'' \(\ker(X)\) and the
``prediction-changing directions'' \(\mathrm{im}(X^\top)\) form a \emph{global} decomposition of
\(\mathbb{R}^P\). For neural networks, we should not expect any global linear structure.
However, the key lesson survives: \emph{locally, the model map looks linear}, and therefore
the parameter space looks like a \emph{local} product of fibre directions and prediction-changing directions.
Figure~\ref{fig:local_trivialization_cartoon} is the picture to keep in mind: near a regular point, you can use
``(prediction coordinates, fibre coordinates)'' so that $F$ just forgets the fibre coordinate.

\paragraph{The dataset-restricted model map.}
Recall that the network produces distributional parameters
\(u_\theta(x)=f_\theta(x)\in\mathcal U\), and the per-datum likelihood is
\(p(y\mid f_\theta(x))\).
Fix a dataset \(\mathcal D=\{(x^{(n)},y^{(n)})\}_{n=1}^N\). The central object of this chapter is the
\emph{dataset-restricted prediction map}
\begin{equation}
  F_{\mathcal D}:\Theta\to\mathcal U^N,
  \qquad
  F_{\mathcal D}(\theta)
  \;:=\;
  \bigl(f_\theta(x^{(1)}),\dots,f_\theta(x^{(N)})\bigr).
  \label{eq:dataset_restricted_map}
\end{equation}
(You can think of \(\mathcal U^N\) as a ``stacked logit space'' or ``stacked natural-parameter space''.)
By construction, the likelihood depends on \(\theta\) only through \(F_{\mathcal D}(\theta)\):
\[
  p(\mathcal D\mid \theta)
  \;=\;
  \prod_{n=1}^N p\bigl(y^{(n)}\mid f_\theta(x^{(n)})\bigr)
  \;=\;
  \mathcal{L}\!\bigl(F_{\mathcal D}(\theta)\bigr)
\]
for a suitable function \(\mathcal{L}:\mathcal U^N\to\mathbb{R}_+\).

\paragraph{Fibres: ``indistinguishable on the dataset''.}
For any \(z\in\mathcal U^N\), the fibre (preimage) is
\begin{equation}
  \mathcal F_z
  \;:=\;
  F_{\mathcal D}^{-1}(z)
  \;=\;
  \{\theta\in\Theta : F_{\mathcal D}(\theta)=z\}.
  \label{eq:fibre_def}
\end{equation}
These are precisely the sets of parameters that produce identical predictions on all training inputs.
When \(f_\theta\) is overparameterized, such fibres can be high-dimensional and can contain
reparameterizations/symmetries (e.g.\ hidden-unit permutations or scaling symmetries).

\paragraph{Local linearization: replacing a network by its first-order approximation.}
Fix a reference point \(\theta_0\in\Theta\) and consider a small perturbation \(\delta\).
A first-order Taylor approximation gives
\begin{equation}
  F_{\mathcal D}(\theta_0+\delta)
  \;\approx\;
  F_{\mathcal D}(\theta_0) \;+\; J_{\mathcal D}(\theta_0)\,\delta,
  \label{eq:local_linearization}
\end{equation}
where
\[
  J_{\mathcal D}(\theta_0)
  \;:=\;
  dF_{\mathcal D}(\theta_0)
\]
is the Jacobian (differential) of the dataset-restricted map. Concretely, it is the stacked Jacobian of
the network outputs at the training inputs. This plays the same role as the design matrix \(X\) in the
linear example.

\paragraph{The first-order ``fibre directions'' are the Jacobian nullspace.}
Equation \eqref{eq:local_linearization} makes one fact immediate:
if \(\delta\in\ker(J_{\mathcal D}(\theta_0))\), then to first order
\[
  F_{\mathcal D}(\theta_0+\delta)\;\approx\;F_{\mathcal D}(\theta_0),
\]
so \(\delta\) is (infinitesimally) prediction-preserving on the dataset. This motivates the definition
of the \emph{vertical space} at \(\theta_0\):
\begin{equation}
  V_{\theta_0}
  \;:=\;
  \ker\!\bigl(dF_{\mathcal D}(\theta_0)\bigr)
  \;=\;
  \ker\!\bigl(J_{\mathcal D}(\theta_0)\bigr),
  \label{eq:vertical_space}
\end{equation}
the tangent directions that do not change dataset predictions (to first order).
In the linear model \(F_{\mathcal D}(\theta)=X\theta\), this reduces to \(V_\theta=\ker(X)\) for all \(\theta\),
which is why the decomposition was global.

\paragraph{Prediction-changing directions: choosing a complement (a ``horizontal'' space).}
The Jacobian also identifies the directions that \emph{do} change predictions.
Any vector \(\delta\) with \(J_{\mathcal D}(\theta_0)\delta\neq 0\) moves the logits in the stacked output space.
To turn this into a clean local product picture, we want to split the full tangent space as
\begin{equation}
  T_{\theta_0}\Theta
  \;\cong\;
  H_{\theta_0}\;\oplus\;V_{\theta_0},
  \qquad
  V_{\theta_0}=\ker(J_{\mathcal D}(\theta_0)),
  \label{eq:local_split_goal}
\end{equation}
where \(H_{\theta_0}\) is any complementary subspace (a choice of ``prediction-changing directions'').

At the informal level, you can think of \(H_{\theta_0}\) as the directions that move you \emph{across} fibres,
while \(V_{\theta_0}\) moves you \emph{along} a fibre. The key subtlety is that in nonlinear models this choice
need not be canonical: different complements correspond to different ways of ``lifting'' a desired change in
predictions back to a parameter update. This is exactly the motivation for introducing an Ehresmann connection
in the formal section.
Figure~\ref{fig:tangent_splitting_cartoon} is the corresponding tangent-space cartoon: $dF_\theta$ kills vertical
(fibre) directions and identifies horizontal directions with changes in prediction space.

\paragraph{Local product structure in words (what to remember).}
The linear case taught us that ``dataset predictions'' live in a lower-dimensional space, and parameters
contain extra degrees of freedom that the dataset cannot see. The nonlinear case keeps exactly the same story,
but only \emph{locally}:
\begin{itemize}[leftmargin=1.4em,itemsep=0.25em]
  \item the map \(F_{\mathcal D}\) replaces the design matrix \(X\);
  \item the nullspace \(\ker(J_{\mathcal D}(\theta_0))\) gives the \emph{local} fibre directions at \(\theta_0\);
  \item a complementary subspace gives the \emph{local} directions that change predictions;
  \item these two pieces vary with \(\theta\), so the ``product'' picture is local rather than global.
\end{itemize}

\paragraph{Bridge to the next (formal) subsection.}
Up to now, we have treated the splitting \eqref{eq:local_split_goal} as a local linear-algebraic convenience.
The next step is to formalize when fibres are genuine smooth submanifolds and when such local product charts exist.
On regions where \(F_{\mathcal D}\) has constant rank, differential topology guarantees exactly this:
the parameter space admits local coordinates in which \(F_{\mathcal D}\) is a projection, and the fibres are smooth
leaves. Introducing an Ehresmann connection then promotes the pointwise choice of complements \(H_{\theta}\) into a
smooth field of horizontal spaces, yielding the intrinsic fibre bundle picture used throughout the thesis.

\subsection{From linear to nonlinear: global subspaces become local distributions}
\label{subsec:nonlinear_localization}

\noindent \textit{(Nonlinear case.)} For neural networks the forward map $F$ is nonlinear, so the Jacobian
\[
J_\theta := dF_\theta
\]
depends on $\theta$. As a result, the vertical directions
\[
\mathrm{Ver}_\theta := \ker(J_\theta)
\]
and the corresponding ``horizontal complements'' vary from point to point. In other words, the global decomposition
\eqref{eq:linear_global_split} is replaced by a \emph{local} decomposition of tangent spaces:
\begin{equation}
\label{eq:local_split}
T_\theta\Theta \;=\; \underbrace{\ker(dF_\theta)}_{\mathrm{Ver}_\theta}
\ \oplus\ 
\underbrace{\mathrm{Hor}_\theta}_{\text{chosen complement}},
\qquad \theta\ \text{in a regular region}.
\end{equation}

\noindent The key message is that \emph{even though the fibres may twist globally}, near a \emph{regular point}
(the regime where the rank of $dF_\theta$ is locally constant) there exist local coordinates in which the map $F$
looks like a projection. This is exactly the ``local product'' behavior captured by the notion of a fibre bundle.

\medskip
\noindent \textit{(Ehresmann connection, informally.)} A smooth choice of complements $\mathrm{Hor}_\theta$ in
\eqref{eq:local_split} is called an \emph{Ehresmann connection}. It formalizes the idea of ``moving across fibres''
versus ``moving along fibres'' and will later allow us to identify $\mathrm{Hor}_\theta$ with tangent directions in the
base (prediction) manifold.


\noindent \paragraph{What this section is promising.}
The next sections make the above cartoons precise: we will (i) recall the minimal fibre bundle definitions,
(ii) define $F$ intrinsically from the Bayesian model, (iii) identify a regular region where $F$ is a submersion onto a
base manifold $B$, and (iv) construct a horizontal/vertical splitting (Ehresmann connection) that will later let us
define geometric computations in a way aligned with the likelihood.

\subsection{Background}
\label{subsec:formal_background}
% ============================================================

\noindent We recall the minimal differential-geometric vocabulary needed to formalize the local product picture from
Section~\ref{sec:informal_local_product}. All objects will later be instantiated by the dataset-restricted prediction
map arising from a Bayesian model.

\begin{gdefn}[Smooth manifold and differential]
A \emph{smooth manifold} $M$ of dimension $d$ is a Hausdorff, second countable topological space equipped with an atlas
of charts $(U,\psi)$ where $\psi:U\to \mathbb{R}^d$ are homeomorphisms with smooth transition maps.
For $p\in M$, the \emph{tangent space} at $p$ is denoted $T_pM$ and the \emph{tangent bundle} is
$TM := \bigsqcup_{p\in M} T_pM$.

Given a smooth map $G:M\to N$, its \emph{differential} at $p$ is the linear map
\[
dG_p : T_pM \to T_{G(p)}N.
\]
We write $\ker(dG_p)\subset T_pM$ for its kernel and $\mathrm{rank}(dG_p)$ for its rank.
\end{gdefn}

\begin{gdefn}[Constant rank and submersion]
A smooth map $G:M\to N$ has \emph{constant rank $r$} on a set $U\subseteq M$ if $\mathrm{rank}(dG_p)=r$ for all $p\in U$.
It is a \emph{submersion} at $p\in M$ if $dG_p$ is surjective.
\end{gdefn}

\begin{gthm}[Constant Rank Theorem (local normal form)]
Let $G:M\to N$ be smooth and suppose $\mathrm{rank}(dG_p)=r$ is constant on a neighborhood of $p\in M$.
Then there exist charts $(U,\psi)$ around $p$ and $(V,\phi)$ around $G(p)$ such that in coordinates
\[
(\phi\circ G\circ \psi^{-1})(a,b) = (a,0),
\qquad (a,b)\in \mathbb{R}^r\times \mathbb{R}^{\dim M-r}.
\]
\end{gthm}

\begin{gdefn}[Smooth fibre bundle]
A \emph{smooth fibre bundle} is a quadruple $(E,B,F,\pi)$ where $E$ and $B$ are smooth manifolds,
$F$ is a smooth manifold (the \emph{typical fibre}), and $\pi:E\to B$ is a smooth surjection such that:

\smallskip
\noindent\textbf{(Local triviality)} For every $b\in B$, there exists an open neighborhood $U\subset B$ and a diffeomorphism
(a \emph{local trivialization})
\[
\varphi_U : U\times F \to \pi^{-1}(U)
\]
satisfying $\pi\circ \varphi_U = \mathrm{pr}_1$, the projection onto the first factor.

\smallskip
\noindent The \emph{fibre over $b$} is $E_b := \pi^{-1}(b)$.
\end{gdefn}

\begin{gdefn}[Vertical bundle and Ehresmann connection]
Let $\pi:E\to B$ be a smooth surjection. The \emph{vertical subspace} at $e\in E$ is
\[
\mathrm{Ver}_e := \ker(d\pi_e)\subset T_eE.
\]
An \emph{Ehresmann connection} is a smooth choice of complementary subspaces $\mathrm{Hor}_e\subset T_eE$ such that
\[
T_eE = \mathrm{Ver}_e \oplus \mathrm{Hor}_e \qquad \text{for all } e\in E.
\]
The subspaces $\mathrm{Hor}_e$ are called the \emph{horizontal spaces}.
\end{gdefn}

\subsection{Background}
\label{subsec:background}

This chapter uses a viewpoint that is standard in modern geometry (and emphasized beautifully in Sharpe’s
\emph{Cartan/Klein} narrative): we should not start by choosing coordinates or a metric; we should start by
identifying the \emph{structure} that the problem naturally provides.
Here, the structure is the dataset-restricted prediction map \(\Phi = F_{\mathcal D}\), and the objects it
creates: fibres, vertical directions, and (after a choice) horizontals.

The purpose of this subsection is not to ``list definitions'', but to build a mental model:
\[
\text{manifold} \;\Rightarrow\; \text{smooth map} \;\Rightarrow\; \text{fibres/foliation}
\;\Rightarrow\; \text{bundle (local product)} \;\Rightarrow\; \text{connection (geometry without a metric)}.
\]

\subsubsection{Manifolds: spaces that can be coordinatized locally (but not globally)}
A recurring confusion in applied work is to treat \(\Theta\) as \(\mathbb{R}^P\) and forget that even when a
space looks Euclidean \emph{locally}, it may not admit a single global coordinate system that behaves nicely
everywhere. The point of manifolds is to formalize the slogan:

\begin{quote}
\emph{A manifold is a space that looks like \(\mathbb{R}^m\) when you zoom in.}
\end{quote}

A \emph{chart} is a local coordinate system. Concretely, a chart on a set \(U\subset M\) is a bijection
\(\varphi:U\to \varphi(U)\subset \mathbb{R}^m\). We require that when two charts overlap, the coordinate change
\(\varphi_2\circ\varphi_1^{-1}\) is smooth. This is exactly what you do implicitly on a sphere:
you cannot cover the sphere with one latitude-longitude chart without singularities, but you can cover it with
multiple overlapping patches.

\subsubsection{Tangent vectors: “infinitesimal motion”}
Once you accept that manifolds are ``coordinate-free'' objects, you need a coordinate-free notion of
\emph{direction}. The right notion is a tangent vector: the velocity of a curve passing through a point.

Formally, take a smooth curve \(\gamma:(-\epsilon,\epsilon)\to M\) with \(\gamma(0)=p\).
Two curves are equivalent if, in some (hence any) chart around \(p\), their coordinate velocities match.
The equivalence class is a tangent vector \(v\in T_pM\).
You can always compute with coordinates, but the meaning is intrinsic:
\[
v = \dot\gamma(0) \quad\text{(a first-order perturbation of \(p\)).}
\]

\subsubsection{Smooth maps and fibres: the geometry created by a model}
A smooth map \(F:M\to B\) is the formal way to encode ``a model produces predictions''.
In our setting \(M=\Theta\) and \(F=F_{\mathcal D}\) maps parameters to stacked predictive quantities (logits/natural parameters).
The most important geometric object produced by a map is its \emph{fibre} (preimage):
\[
F^{-1}(b) := \{\theta\in \Theta : F(\theta)=b\}.
\]
This matches your informal definition exactly: a fibre is a set of parameters that are indistinguishable on
the dataset.

The differential \(dF(\theta):T_\theta\Theta\to T_{F(\theta)}B\) is the intrinsic Jacobian.
Its kernel is the infinitesimal fibre direction:
\[
\ker dF(\theta) \quad\text{are precisely the directions that do not change \(F(\theta)\) to first order.}
\]

\subsubsection{Why the constant rank theorem is the “local product theorem”}
The bridge from linear algebra to geometry is the constant rank theorem. Instead of stating it as a formal
coordinate-normal-form theorem, here is the picture it gives you:

\begin{quote}
\emph{If \(F\) has constant rank near \(\theta_0\), then near \(\theta_0\) you can choose coordinates so that
\(F\) literally looks like a projection onto the first \(r\) coordinates. Hence the space nearby looks like
``(base coordinates) \(\times\) (fibre coordinates)''.}
\end{quote}

\subsubsection{Fibre bundles: families of fibres that look like products locally}
A fibre bundle is the global packaging of the previous picture. Instead of saying
``around \(\theta_0\), the space looks like base \(\times\) fibre'',
a bundle says:

\begin{quote}
\emph{Around each base point \(b\), the preimage \(F^{-1}(U)\) looks like \(U\times \mathcal F\).}
\end{quote}

The key new ingredient is that the product structure is allowed to \emph{twist} globally.
The classic intuition is the cylinder vs the M\"obius strip.

\subsubsection{Where geometry enters: connections give “horizontal motion” without a metric}
Up to now we have only talked about fibres (vertical directions). But the moment you want to compare
\emph{different fibres}—for example, to say what it means to ``move in parameter space while changing
predictions in a controlled way''—you need extra structure.

Sharpe’s central lesson (in the Cartan/Klein style) is: geometry is about \emph{comparison}.
A connection is precisely a rule for comparing nearby fibres.

\paragraph{Vertical directions are canonical.}
Given a projection \(\pi:E\to B\) (in our case \(\pi = F_{\mathcal D}\) on a regular region),
the vertical subspace at \(u\in E\) is
\[
V_uE := \ker(d\pi(u)).
\]
This is not a choice: it is forced by the map.

\paragraph{Horizontal directions are a choice: an Ehresmann connection.}
An \emph{Ehresmann connection} is a smooth choice of complements \(H_u\) satisfying
\[
T_uE = H_u \oplus V_uE.
\]
Intuitively:
\begin{itemize}[leftmargin=1.4em,itemsep=0.25em]
  \item \(V_uE\): infinitesimal moves that stay on the same fibre (do not change predictions).
  \item \(H_u\): infinitesimal moves that change the base point (change predictions), i.e.\ move across fibres.
\end{itemize}

Once you have \(H\), you can do \emph{geometry}:
\begin{enumerate}[leftmargin=1.4em,itemsep=0.35em]
\item \textbf{Horizontal lift:} given a small desired change in the base, choose the unique horizontal
move in parameters that achieves it.
\item \textbf{Parallel transport:} carry a fibre element along a base curve by staying horizontal.
\item \textbf{Holonomy:} loop in the base may return you to a different point in the fibre (path dependence).
\end{enumerate}
None of this requires a Riemannian metric; it requires only the bundle structure plus a connection.

\paragraph{How this connects back to Bayesian deep learning.}
In our application:
\begin{itemize}[leftmargin=1.4em,itemsep=0.25em]
\item \(E=\Theta\) is parameter space (or a regular region of it).
\item \(B\) is the space of dataset-restricted predictive quantities (stacked logits/natural parameters).
\item \(\pi = F_{\mathcal D}\) is the dataset-restricted prediction map.
\item Fibres are equivalence classes of parameters that agree on \(\mathcal D\).
\item \(V_\theta = \ker(dF_{\mathcal D}(\theta))\) are the infinitesimal ``sloppy'' directions.
\item Choosing a horizontal complement \(H_\theta\) is exactly choosing an intrinsic way to convert
``desired changes in predictions'' into ``parameter updates''.
\end{itemize}

The next subsection uses this language to state a precise regularity assumption (constant rank / submersion on a
region) under which \(\Theta\) acquires a local bundle structure over \(B\), and then introduces an Ehresmann
connection as the mechanism that makes the horizontal/vertical splitting smooth across the region.

% ============================================================
\section{Parameter Manifold}
\label{subsec:parammanifold_formal}
% ============================================================

\noindent We now define the specific bundle relevant to Bayesian deep learning. The construction is intrinsic: the base
manifold is \emph{defined} as the image of the dataset-restricted prediction map endowed with the smooth structure
induced by the constant rank theorem.

\begin{gassm}[Probabilistic model and dataset-restricted prediction map]
We fix a dataset $\mathcal{D}=\{(x_n,y_n)\}_{n=1}^N$ with $x_n\in\mathcal{X}$ and $y_n\in\mathcal{Y}$.
Let $\Theta\subset\mathbb{R}^P$ be an open set (parameter space).

\begin{enumerate}[leftmargin=1.5em,itemsep=0.25em]
  \item \textbf{(Likelihood through predictions)} There exists a finite-dimensional prediction space $\mathcal{U}$
  (e.g.\ logits or natural parameters on $\{x_n\}$) and a smooth map
  \[
  F:\Theta\to \mathcal{U}
  \]
  such that the (dataset) likelihood depends on $\theta$ only through $F(\theta)$:
  \[
  p(\mathcal{D}\mid \theta) \;=\; \widetilde p\!\left(\mathcal{D}\mid F(\theta)\right)
  \quad\text{for some function }\widetilde p.
  \]
  Concretely, one may take
  \[
  F(\theta) = \bigl(f_\theta(x_1),\dots,f_\theta(x_N)\bigr)\in \mathbb{R}^{N\cdot O}.
  \]

  \item \textbf{(Smoothness)} The map $F$ is $C^\infty$ (or $C^k$ for sufficiently large $k$), so its differential
  $dF_\theta$ exists for all $\theta\in\Theta$.
\end{enumerate}
\end{gassm}

\begin{gdefn}[Fibres (dataset-level identifiability classes)]
For $u\in\mathcal{U}$, define the \emph{fibre} (equivalence class) over $u$ by
\[
\mathcal{F}_u := F^{-1}(u) = \{\theta\in\Theta : F(\theta)=u\}.
\]
Two parameters $\theta,\theta'\in\Theta$ are \emph{dataset-indistinguishable} if $\theta\sim\theta'$ where
$F(\theta)=F(\theta')$.
\end{gdefn}

\begin{gdefn}[Stacked Jacobian]
For $\theta\in\Theta$, the differential $dF_\theta:T_\theta\Theta\to T_{F(\theta)}\mathcal{U}$ is represented in
standard coordinates by a Jacobian matrix $J_\theta$.
When $F(\theta)=(f_\theta(x_1),\dots,f_\theta(x_N))$, this is the stacked Jacobian
\[
J_\theta =
\begin{bmatrix}
\frac{\partial f_\theta(x_1)}{\partial \theta}\\
\vdots\\
\frac{\partial f_\theta(x_N)}{\partial \theta}
\end{bmatrix}
\in \mathbb{R}^{(N\cdot O)\times P}.
\]
\end{gdefn}

\begin{gassm}[Regular region (constant-rank regime)]
There exists an open subset $\Theta_{\mathrm{reg}}\subseteq \Theta$ and an integer $r$ such that
\[
\mathrm{rank}(dF_\theta) = \mathrm{rank}(J_\theta) = r
\qquad \text{for all }\theta\in \Theta_{\mathrm{reg}}.
\]
\end{gassm}

\begin{gdefn}[Intrinsic base]
Define the \emph{base set} as the image of the regular region:
\[
B := F(\Theta_{\mathrm{reg}})\subseteq \mathcal{U}.
\]
\end{gdefn}

\begin{gprop}[Intrinsic manifold structure on the base]
Under the regularity Assumption above, the set $B=F(\Theta_{\mathrm{reg}})$ carries a natural smooth manifold structure
of dimension $r$ such that $F:\Theta_{\mathrm{reg}}\to B$ is a smooth submersion.
\end{gprop}

\noindent\textit{Proof (sketch).}
Fix $\theta_0\in\Theta_{\mathrm{reg}}$ and apply the constant rank theorem to $F$ at $\theta_0$.
In local coordinates $(a,b)\in\mathbb{R}^r\times\mathbb{R}^{P-r}$ around $\theta_0$ and suitable coordinates around
$u_0=F(\theta_0)$, the map takes the form $(a,b)\mapsto (a,0)$. The image near $u_0$ is thus locally diffeomorphic to
$\mathbb{R}^r$; these coordinate patches define a smooth atlas on $B$, and by construction $dF_\theta$ is surjective
onto $T_{F(\theta)}B$ on $\Theta_{\mathrm{reg}}$.
\hfill$\square$

\begin{gprop}[Fibres are submanifolds and the vertical tangent space]
Under the regularity Assumption, for each $u\in B$ the fibre $\mathcal{F}_u = F^{-1}(u)$ is an embedded submanifold of
$\Theta_{\mathrm{reg}}$ of dimension $P-r$. Moreover, for any $\theta\in\mathcal{F}_u$,
\[
T_\theta \mathcal{F}_u = \ker(dF_\theta) = \ker(J_\theta).
\]
\end{gprop}

\noindent\textit{Proof (sketch).}
In the constant rank coordinates where $F(a,b)=(a,0)$, the fibre through $(a_0,b_0)$ is the slice $\{(a,b):a=a_0\}$,
which is a smooth $(P-r)$-dimensional submanifold parametrized by $b$. Its tangent space is exactly the set of
directions with $\delta a=0$, i.e.\ $\ker(dF_\theta)$ in those coordinates, and hence in general.
\hfill$\square$

\begin{gthm}[Local fibre bundle structure induced by $F$]
Under the regularity Assumption, the map $F:\Theta_{\mathrm{reg}}\to B$ is locally trivial: for every $\theta_0\in
\Theta_{\mathrm{reg}}$ there exists a neighborhood $U\subset B$ of $u_0=F(\theta_0)$ and a diffeomorphism
\[
\varphi: U\times \mathcal{F}^{\mathrm{loc}}_{u_0} \to F^{-1}(U)
\]
such that $F\circ \varphi = \mathrm{pr}_1$. In particular, $(\Theta_{\mathrm{reg}},B,\mathcal{F},F)$ forms a smooth
fibre bundle locally around $\theta_0$.
\end{gthm}

\noindent\textit{Proof (sketch).}
Apply the constant rank theorem at $\theta_0$ to obtain coordinates $(a,b)$ on a neighborhood $V\subset\Theta_{\mathrm{reg}}$
in which $F(a,b)=(a,0)$. Let $U$ denote the corresponding neighborhood of $u_0$ in $B$ (identified with the $a$-coordinates).
Then $V \cong U\times F_{\mathrm{loc}}$ and on $V$ the map $F$ is projection onto $U$. Pulling this product structure
back through the coordinate chart gives the required local trivialization $\varphi$.
\hfill$\square$

\begin{gdefn}[Vertical bundle and horizontal bundle for the prediction map]
For $\theta\in\Theta_{\mathrm{reg}}$, define the \emph{vertical space}
\[
\mathrm{Ver}_\theta := \ker(dF_\theta)\subset T_\theta\Theta_{\mathrm{reg}}.
\]
An \emph{Ehresmann connection} for $F$ is a smooth choice of subspaces $\mathrm{Hor}_\theta$ such that
\[
T_\theta\Theta_{\mathrm{reg}} = \mathrm{Ver}_\theta \oplus \mathrm{Hor}_\theta.
\]
\end{gdefn}

\begin{gprop}[Horizontal identification with the base tangent space]
Let $F:\Theta_{\mathrm{reg}}\to B$ be as above and let $\mathrm{Hor}$ be an Ehresmann connection.
Then for every $\theta\in\Theta_{\mathrm{reg}}$ the restricted map
\[
dF_\theta\big|_{\mathrm{Hor}_\theta} : \mathrm{Hor}_\theta \to T_{F(\theta)}B
\]
is a linear isomorphism.
\end{gprop}

\noindent\textit{Proof.}
Since $F$ is a submersion onto $B$, the map $dF_\theta:T_\theta\Theta_{\mathrm{reg}}\to T_{F(\theta)}B$ is surjective.
Its kernel is $\mathrm{Ver}_\theta$. On the direct sum decomposition
$T_\theta\Theta_{\mathrm{reg}}=\mathrm{Ver}_\theta\oplus \mathrm{Hor}_\theta$, the restriction of $dF_\theta$
to $\mathrm{Hor}_\theta$ is injective and surjective, hence an isomorphism.
\hfill$\square$

\begin{grem}[A canonical choice of connection (optional)]
Choosing an inner product on $T_\theta\Theta_{\mathrm{reg}}$ yields a canonical complement
$\mathrm{Hor}_\theta := \mathrm{Ver}_\theta^\perp$.
With the Euclidean inner product in coordinates, $\mathrm{Hor}_\theta = \ker(J_\theta)^\perp = \mathrm{im}(J_\theta^\top)$,
so
\[
T_\theta\Theta_{\mathrm{reg}} \;=\; \ker(J_\theta)\ \oplus\ \mathrm{im}(J_\theta^\top).
\]
\end{grem}

\begin{grem}[Outside the regular region]
If $\mathrm{rank}(J_\theta)$ changes, fibre dimensions can change and the above smooth bundle description may fail
globally (one typically obtains stratified geometry). In this thesis we develop the theory on regular regions where the
bundle and connection constructions are valid and sufficient for the subsequent analysis.
\end{grem}
